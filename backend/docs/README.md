# Backend Documentation Index

This folder is the long-lived documentation set for the Ecommerge backend.

## Read first

1. [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md)
2. [ARCHITECTURE.md](ARCHITECTURE.md)

## Document map

- `PROJECT_OVERVIEW.md`: repository and platform overview, current implementation status, service map, runtime model.
- `ARCHITECTURE.md`: DDD context map, communication patterns, data ownership, event topology, AI architecture.
- `API_REFERENCE.md`: gateway and service endpoint catalog, request/response expectations, implementation status.
- `ENVIRONMENT.md`: ports, infrastructure dependencies, environment variables, profiles, and local run notes.

## Supporting materials

- `diagrams/`: supporting diagrams and context-map notes.

Use the four top-level documents above as the canonical documentation set. Diagram notes are supplementary and may lag behind the code if they are not updated in the same change.
